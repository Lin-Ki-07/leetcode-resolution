# LeetCode 题解

这个仓库收录 LeetCode 题目的多语言解法与中文讲解，供学习、复习和交流使用。目前我主要使用 Python，欢迎贡献其他语言的题解。每篇题解尽量说明必要的基础知识、解题思路、代码实现、复杂度和容易出错的情况。

## 目录结构

```text
.
├── README.md
├── LICENSE
├── CONTRIBUTING.md
├── .gitignore
└── problems/
    └── python/         # 按语言保存 Markdown 题解
```

题解按语言分目录，文件按 `四位题号-英文短名.md` 命名，例如 `problems/python/0001-two-sum.md`。贡献其他语言时可建立对应目录，例如 `problems/c/`。同一道题的不同语言解法可以分别收录。
